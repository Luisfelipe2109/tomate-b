# El Tomate Mecánico — Landing Page (Next.js)

Landing page oficial de la escuela de fútbol formativo **El Tomate Mecánico** construida con **Next.js (App Router)** y **Tailwind CSS**.

## Despliegue en Vercel
1. Conecta este repositorio en tu cuenta de [Vercel](https://vercel.com).
2. En la configuración de importación, en **Root Directory**, haz clic en *Edit* y selecciona **`tomate-b`**.
3. Haz clic en **Deploy**.

## Ejecución Local
```bash
cd tomate-b
npm install
npm run dev
```
Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
